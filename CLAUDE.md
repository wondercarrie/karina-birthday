# CLAUDE.md

Правила проекта для сессий Claude Code. Подробности о структуре и инструментах — в README.md,
известные проблемы и идеи — в BACKLOG.md.

## Проект

- Одностраничное приглашение на день рождения, статический лендинг на GitHub Pages:
  `index.html`, `styles.css`, `script.js`, `assets/` (`img/`, `fonts/`).
- Без сборки и без внешних CDN: шрифты и картинки лежат в `assets/`. Новые зависимости в сам сайт
  не добавлять. `tools/visual/` — инструменты проверки, не часть сайта, у него свой `package.json`.
- Брейкпоинты: десктоп > 1050px (контент максимум 1200px), планшет 761–1050px, мобильный ≤ 760px.
- Порядок `styles.css`: шрифты → токены (`:root`) → reset и base → лейаут → общие компоненты →
  секции в порядке страницы → reveal-анимация → медиа-запросы (планшет, мобильный, reduced motion).
  Новые правила класть в соответствующий раздел.

## Тексты

- Тексты RU/EN живут в объекте `COPY` в `script.js`, ключ — атрибут `data-copy` элемента.
- Любой новый текст — сразу на двух языках.
- Текст в `index.html` — русская версия до запуска скрипта, держать её синхронной с `COPY.ru`.

## CSS

- Статичные отступы и размеры — только из шкалы переменных `--space-*` (кратно 4px), шрифты —
  из `--text-*`. Нужного шага нет — добавить переменную в шкалу в `:root`, а не писать число.
- Единицы — `rem` (1rem = 16px). В `px` допустимы только `border: 1px` и медиа-запросы.
- Относительные и fluid-значения (`%`, `vw`, `clamp()`, `calc()` от них) допустимы, но их
  статичные границы должны лежать на шкале.
- Анимации — только через `transform` и `opacity` (плюс `filter`, где без него никак), без сдвига
  вёрстки.

## Типографика

- RU: неразрывные пробелы между числом и словом, после коротких предлогов и союзов.
- EN: неразрывные пробелы между числом и словом.

## Доступность

- Любая анимация отключается или упрощается при `prefers-reduced-motion: reduce`.
- Декоративные элементы — с `aria-hidden="true"`.

## Проверка

- Визуальная регрессия через `tools/visual/` (`shoot.mjs`, `compare.mjs`, `report.mjs`, см. README):
  снимок до изменения и после. Скриншоты снимаются с эмуляцией `reducedMotion: 'reduce'`, чтобы
  анимации не мешали сравнению.
- Отличия от предыдущего коммита допустимы только в области, которую правил; для чистого
  рефакторинга ожидается 0px разницы.
- Анимации ревьюить по видео: Playwright `recordVideo`, ширины 375 и 1440px, файлы в
  `tools/visual/videos/` (в `.gitignore`).
- Консоль без ошибок (`shoot.mjs` пишет ошибки консоли, упавшие запросы и горизонтальный overflow
  в `shots/<name>/meta.json`).
